❓ কীভাবে ব্যবহার করবে? (সহজ হেল্প গাইড)
মনে রাখবেন: ডেমোটি তৈরি হওয়ার পর অবশ্যই পাঠ্যবইয়ের ছবি, সূত্র, সাল-তারিখ বা ব্যাকরণের নিয়মের সাথে মিলিয়ে দেখবে। কোনো তথ্য বা উদাহরণ ভুল মনে হলে Gemini-কে লিখবে: "বইয়ের নিয়ম অনুযায়ী [অংশের নাম]-এর তথ্য বা উদাহরণ ঠিক করে দাও।"

সহজ ব্যবহার নির্দেশিকা (Help Guide)

কোনো কোডিং বা ভিডিও এডিটিং না জেনেই তুমি নিজেই জীবনবিজ্ঞান, ভৌতবিজ্ঞান, গণিত, ভূগোল, ইতিহাস ও ব্যাকরণের কঠিন অধ্যায়গুলোকে চলমান সিমুলেশন বা ভিজ্যুয়াল চার্টে বদলে ফেলতে পারো। নিচের সহজ ধাপগুলো অনুসরণ করো:

ধাপ ১: প্রম্পট (নির্দেশ) তৈরি করো

  1. মূল পাতা থেকে তোমার মাধ্যম (বাংলা বা ইংরেজি), বিষয় ও শ্রেণি বেছে নাও।
  2. বক্সে যে বিষয়টি বুঝতে চাও তার নাম বা সংক্ষিপ্ত বিবরণ লেখো (যেমন: হৃৎপিণ্ডে রক্ত চলাচল, পিথাগোরাসের উপপাদ্য, Tense-এর পরিবর্তন বা কারক ও বিভক্তি)।
  3. 'প্রম্পট তৈরি করুন' বাটনে চাপো এবং নিচে তৈরি হওয়া লেখাটি 'প্রম্পট কপি করুন' বাটনে টিপে কপি করে নাও।

ধাপ ২: Google Gemini-তে লাইভ ডেমো চালাও

  1. মোবাইল বা কম্পিউটারের ব্রাউজারে gemini.google.com খোলো (১৩ বছরের কম বয়স হলে বাবা-মা বা শিক্ষকের সাহায্য নাও)।
  2. কপি করা লেখাটি চ্যাট বক্সে পেস্ট করে পাঠিয়ে দাও।
  3. কয়েক সেকেন্ডের মধ্যেই Gemini তোমার জন্য একটি ইন্টারঅ্যাক্টিভ ল্যাব বা ভিজ্যুয়াল চার্ট তৈরি করে দেবে! বাটন বা স্লাইডার সরিয়ে পরিবর্তনগুলো নিজের চোখে দেখে নাও।

ধাপ ৩: ইন্টারনেট ছাড়াই দেখার জন্য সেভ করে রাখো (কম্পিউটার ও মোবাইল)

  • প্রথমে Gemini-র তৈরি কোড বক্সের ওপরে থাকা Copy code বাটনে ক্লিক করে কোডটি কপি করো।
  • কম্পিউটার বা ল্যাপটপ হলে: Notepad খুলে কোডটি পেস্ট করো এবং File > Save As-এ গিয়ে ফাইলটির নাম দাও demo.html। ফাইলটিতে ডাবল ক্লিক করলেই অফলাইনে চলবে।
  • মোবাইল ফোন হলে: প্লে-স্টোর থেকে ফ্রি QuickEdit বা Acode অ্যাপ ইনস্টল করো। অ্যাপটি খুলে কোডটি পেস্ট করো এবং demo.html নামে ফোনের মেমোরিতে সেভ করো (শেষে .html লেখা জরুরি)। এরপর ফাইল ম্যানেজারে গিয়ে ফাইলটিতে ট্যাপ করে Chrome ব্রাউজার দিয়ে খুললেই ইন্টারনেট ছাড়াই পরীক্ষার আগে রিভিশন দিতে পারবে!
সবচেয়ে জরুরি কথা (সতর্কতা): AI-এর বানানো ডেমোটি সবসময় তোমার পাঠ্যবইয়ের ছবি, সূত্র, সাল-তারিখ বা ব্যাকরণের নিয়মের সাথে মিলিয়ে নেবে। যদি দেখো কোনো তথ্য, হিসাব বা উদাহরণ ভুল হচ্ছে, তবে Gemini-কে বলো—"বইয়ের নিয়ম অনুযায়ী এটি ঠিক করে দাও।" আর কখনোই AI চ্যাটে নিজের নাম, স্কুল বা ঠিকানা লিখবে না।

Without knowing any coding or animation software, you can turn complex Life Science, Physical Science, Mathematics, Geography, History, and Grammar topics into live, interactive simulations and visual charts. Just follow these simple steps:

Step 1: Generate Your Prompt

  1. Select your Medium (Bengali or English), Subject, and Class Level.
  2. Type the topic or a brief description of what you want to visualize (e.g., Blood Circulation in Heart, Pythagoras Theorem, Tense Conversion, or Active & Passive Voice).
  3. Click 'Generate Prompt' and copy the generated text using the Copy Prompt button.

Step 2: Run the Live Simulation in Google Gemini

  1. Open gemini.google.com in your mobile or computer browser (if you are under 13, use it with a parent or teacher).
  2. Paste the copied prompt into the chat box and send it.
  3. Within seconds, Gemini will build an interactive visual demo! Use the buttons or sliders inside the demo to observe how the rules, formulas, or processes work step-by-step.

Step 3: Save for Offline Revision (Computer & Mobile)

  • First, click Copy code at the top of the code block generated by Gemini.
  • On a Computer or Laptop: Open Notepad, paste the code, and save the file as demo.html. Double-click the saved file anytime to run it offline.
  • On a Smartphone: Install a free text editor app like QuickEdit or Acode from the Play Store. Paste the code and save it as demo.html (the .html extension is required). Open your phone's File Manager, tap on demo.html, and open it with Chrome to revise anytime without an internet connection!
Important Safety & Accuracy Tip: Always verify the AI-generated demo against your school textbook diagrams, formulas, dates, and grammar rules. If any rule, calculation, or example looks incorrect, tell Gemini: "Please fix this according to my textbook." Never share your real name, school name, or personal details in AI chats.
